# ちい虐ルーム — GitHub Pages公開用ファイル

現在のアプリをそのまま公開できる一式です。HTML・CSS・JavaScriptだけで動作し、ビルド・サーバー契約・APIキーは不要です。

## まず行うこと

1. このZIPを展開します。ZIPそのものをGitHubにアップロードしてもゲームは公開されません。
2. GitHubで新しい **Public** リポジトリを作成します。名前の例は `chii-room` です。
3. リポジトリの **Add file → Upload files** を開き、このフォルダーの「中身」をまとめてアップロードします。`chii-github-pages` フォルダーそのものをリポジトリの中に作らないでください。
4. **Commit changes** で保存します。
5. **Settings → Pages → Build and deployment** を開きます。
6. **Source: Deploy from a branch**、**Branch: main**、**Folder: / (root)** を選び、**Save** を押します。ブランチ名を別名で作った場合は、そのブランチを選びます。
7. しばらく待ち、Pages画面に表示された公開URLを開きます。

公開URLの形式は `https://あなたのGitHubユーザー名.github.io/リポジトリ名/` です。実際のURLはPages画面で確認してください。公開後はGitHubやChatGPTへのログインなしで遊べます。

## 正しいファイルの置き方

| リポジトリ直下の項目 | 役割 |
| --- | --- |
| `index.html` | ゲーム画面の入口 |
| `styles.css` | 見た目・スマートフォン用の配置 |
| `js/` | ゲーム本体。29ファイルをフォルダーごと配置 |
| `.nojekyll` | GitHub Pagesへ、そのまま配信するよう指定する空ファイル |
| `README.md` | この公開手順 |

ゲーム本体は31ファイル、公開設定用の `.nojekyll` とこの説明を合わせて33ファイルです。`index.html` がリポジトリの最上位に見え、同じ階層に `styles.css` と `js` があれば正しい配置です。

**`js` の中のファイルを外へ出したり、名前を変更したりしないでください。** ファイル同士は相対パスで読み込みます。

`.nojekyll` は隠しファイルです。端末のファイル画面で表示できない場合は、GitHubの **Add file → Create new file** でファイル名を `.nojekyll` として作成してください。内容は空にします。

## iPhoneで作業する場合

「ファイル」アプリでZIPをタップすると展開できます。複数フォルダーを保持したアップロードが難しい場合は、PCのブラウザーで展開済みフォルダーの中身をGitHubのアップロード画面へドラッグすると確実です。iPhoneで `js` の中身だけを選び、リポジトリ直下に配置しないよう注意してください。

## 動かない場合

- リポジトリのファイル一覧はゲームの公開URLではありません。**Settings → Pages** に表示されるURLを開きます。
- 404になる場合は、Pages設定のブランチと `/ (root)`、および直下に `index.html` があるか確認します。
- 画面だけ出て動かない場合は、`js` フォルダーの配置と、29ファイルが揃っているか確認します。
- 初回公開や更新の反映に数分かかることがあります。Pages画面やActionsの公開処理が成功した後に再読み込みしてください。
- 展開した `index.html` の直接タップは、ファイル閲覧になりJavaScriptの読み込みが制限されることがあります。公開URLで確認してください。

## 更新方法

修正後のファイルを、同じリポジトリの同じ場所へ上書きしてCommitします。Pages設定が済んでいれば自動的に更新されます。公開URLは変わりません。

## このセットの内容

- 表情・姿勢のプレビューは詳細・記録の最下部に配置。
- 捕獲場所と体長は個体ごとに生成・保存。
- 絶望からの復帰は恐怖90未満・満足50以上を10秒連続維持。
- セーブは各プレイヤーのブラウザーに保存されます。共有データベースはありません。
